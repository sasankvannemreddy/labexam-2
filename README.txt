COLLEGE WEBSITE - REACT COMPONENT RENDERING

How to run:
1. Extract the college-website.zip file.
2. Open the extracted college-website folder in VS Code.
3. Open Terminal > New Terminal.
4. Run: npm.cmd install
5. Run: npm.cmd run dev
6. Open the Local URL shown in the terminal (usually http://localhost:5173/).

This project renders four React components one below another:
Header, About, Courses, and Contact.
